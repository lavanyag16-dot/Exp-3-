# Exp - 3 RAILWAY MANAGEMENT SYSTEM

# AIM:
To develop a Railway Reservation System that enables users to book, cancel, and check the status of train tickets, while managing train schedules, seat availability, and passenger records efficiently.

# SRS (Procedure):
### Procedure

**Step 1: Problem Identification**
Identify the need for a Railway Reservation System to manage ticket booking, cancellation, and status checking.

**Step 2: Requirement Analysis**
Identify user requirements such as searching trains, booking tickets, cancelling tickets, checking status, and managing train schedules and passenger records.

**Step 3: System Design**
Design the Railway Reservation System using UML diagrams in StarUML:

* Use Case Diagram
* Activity Diagram
* Class Diagram
* Sequence Diagram
* Communication Diagram
* Package Diagram

**Step 4: Database Design**
Create tables for Train, Passenger, Booking, User, Payment, Schedule, and Station with proper relationships.

**Step 5: Implementation**
Develop the required modules for train search, ticket booking, cancellation, status checking, and administration.

**Step 6: Testing**
Test the system to ensure all functions work correctly and handle errors properly.

**Step 7: Result**
The Railway Reservation System is successfully designed to manage train schedules, ticket reservations, cancellations, and passenger details efficiently.
